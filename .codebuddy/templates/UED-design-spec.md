## 1. 整体布局架构

系统采用经典的三栏管理后台布局：**顶部导航栏 + 左侧菜单栏 + 主内容区**。

### 1.1 骨架结构

| 区域 | 规格 | 说明 |
|------|------|------|
| 顶部导航栏 | 高度 48px，全宽固定，阴影 `0 2px 8px rgba(43,127,255,0.3)` | 层级最高，始终可见 |
| 左侧菜单栏 | 宽度 216px（展开）/ 48px（收起） | 固定定位，支持折叠 |
| 菜单项高度 | 40px（一级）/ 36px（二级） | 文字行高对齐，图标居中 |
| 主内容区 | 剩余宽度 | 包含标签页 + 页面内容 |
| 标签栏 | 高度 36px | 位于主内容区顶部 |
| 底部状态栏 | 高度 34px，全宽 `position: fixed`，z-index: `var(--z-overlay)`，顶部 0.5px 细线 | 全局可见，横跨全屏（含侧边栏区域），详见 §29 |

### 1.2 内容区内边距

> ⚠️ v1.5 注意：`.layout` 容器高度需扣除顶部导航栏（48px）和底部状态栏（34px）：
> `height: calc(100vh - var(--topnav-h) - 34px)`

| 区域 | 内边距 |
|------|--------|
| 页面标题区 | 16px 20px（上下 16px，左右 20px） |
| 搜索筛选区 | 12px 20px，底部分隔线 |
| 搜索区与表格区间距 | 12px |
| 表格 / 内容区 | margin 8px（上/左/右均为 8px），表格撑满宽度 |

### 1.3 页面标题

- 字号 16px，字重 500
- 左对齐，无图标
- 页面标题与操作按钮（如「新增」）左右分布（flex + space-between）

## 4. 导航规范

### 4.1 左侧菜单结构

- **一级菜单**：带 SVG 图标 + 文字 + 展开箭头（SVG 三角），点击切换折叠
- **二级菜单**：仅文字，展开后内缩（padding-left: 46px），无图标或有小尺寸装饰图标
- **三级菜单**：原型中未落地（v1.3 标注）；若后续需要则使用二级菜单 hover 时右侧弹出悬浮面板
- 一级菜单未展开时，默认收起二级菜单列表

### 4.2 菜单交互

| 状态 | 效果 |
|------|------|
| 默认 | 文字色 `#666`，背景透明 |
| Hover | 背景 `#F0F5FF`，文字不变色 |
| 激活（一级，有子菜单） | 浅蓝背景 `#F0F5FF`，文字色 `#333`，字重 500，左侧 2px 蓝色指示条 |
| 激活（一级，无子菜单） | 同上有子菜单激活态 |
| 激活（二级） | 全行背景 `#E6F1FB`，文字 `#1677FF`，左侧 3px 蓝色竖条指示器 |
| 图标颜色 | 默认跟随文字色 `#666`，激活时 `#1677FF` |
| 展开箭头 | 16×16px 容器，内部 12px SVG 箭头；展开时旋转 90°（`transition: transform 0.25s`） |
| 展开动画 | 高度动画（max-height: 0 → 500px），`transition: max-height 0.25s ease` |
| **焦点** | `:focus-visible` 时显示 2px 蓝色外边框 `#2B7FFF`，`outline-offset: -2px`（内侧） |

### 4.3 菜单宽度

- 展开态：216px
- 收起态：48px（仅显示图标，菜单文字、箭头、子菜单均隐藏）
- 菜单项高度：40px（一级）、36px（二级）
- 收起后二级菜单不显示

## 5. 多标签页（Multi-Tab）

### 5.1 标签栏规则

| 属性 | 值 |
|------|-----|
| 高度 | 36px |
| 标签最大宽度 | 160px，超出省略号截断 |
| 激活状态 | 蓝色文字 `#1677FF` + 底部 2px 蓝色下划线 + 字重 500 |
| 关闭按钮 | Hover 后出现 `×` 图标，位于标签右侧（同时显示 SVG 图标 + 文字） |
| 工作台标签 | 始终存在，不可关闭（无 `×` 图标） |
| 标签间距 | 2px |
| 标签内图标 | 16px SVG 图标，在文字左侧 |

### 5.2 导航路径规则

1. 点击左侧菜单 → 在标签栏新增一个标签并自动激活
2. 同一页面重复点击 → 不新增标签，直接激活已有标签
3. 标签数超出可视宽度 → 标签栏出现横向滚动（`overflow-x: auto`）
4. 关闭标签 → 自动激活相邻标签；关闭最后一个标签时回到工作台

## 6. 查询筛选区

### 6.1 筛选区布局

- 采用 3 列 Grid 布局（`grid-template-columns: repeat(3, 1fr)`），列间间距 16px，行间距 12px
- 筛选控件采用内部 Grid：标签固定 `5em` + 控件 `1fr`，确保各列标签水平对齐
- 查询 / 重置按钮固定在第三列末尾，用 flex 末尾定位
- 超过两行筛选条件时，提供「展开 ▾」/「收起 ▴」入口

### 6.2 控件规格

| 控件 | 规格 |
|------|------|
| 输入框 | 高度 32px，宽度自适应（100%），超出换行 |
| 下拉框 | 高度 32px，最小宽度自适应，默认值「全部」 |
| 日期区间 | 两个日期输入框 + `~` 连接符 |
| 日期默认值 | 最近 30 天或当月 |

### 6.3 交互行为

| 行为 | 说明 |
|------|------|
| 回车触发 | 输入框内按 Enter 即触发查询 |
| 重置逻辑 | 清空全部筛选值，恢复默认并自动重查 |
| 默认值 | 下拉默认为「全部」，表示不筛选该维度 |
| 查询反馈 | 查询触发列表刷新，保持分页不变（回到第 1 页） |

## 8. 弹窗（Dialog/Modal）

### 8.1 基础规格

| 属性 | 值 |
|------|-----|
| 宽度 | 640px（标准）/ 500px（审批确认）/ 440px（删除确认） |

### 8.2 弹窗结构

```
┌──────────────────────────────────┐
│ 标题                    × 关闭   │  ← 标题栏：14px / 500，主色 #2B7FFF
├─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┤  ← 分隔线：1px solid，与标题同色（#2B7FFF）
│                                  │
│  字段1  字段2  字段3             │  ← 三列 Grid 布局（gap: 16px 24px）
│  字段4  字段5  字段6             │
│                                  │
│  | 分组标题                      │  ← 左侧 3px 蓝条 + 加粗（.section-title）
│  Group separator                 │  ← 1px dashed #D9E8F6（.section-divider）
│  字段...                         │
│                                  │
├──────────────────────────────────┤
│              [关闭]  [确定]       │  ← 底部按钮区，右对齐
└──────────────────────────────────┘
```

### 8.3 内容展示规则

| 规则 | 说明 |
|------|------|

## 18. 交互通用原则

### 18.1 操作路径分级

```
列表页（查询 + 摘要）     →   弹窗（查看/编辑详情）     →   详情页（完整配置）
────────────────────────────────────────────────────────────────────────
触发方式：菜单导航          触发方式：点击行「查看」「编辑」  触发方式：点击「设置」
容器：多标签页内            容器：覆盖层（弹窗）              容器：独立标签页
特点：批量筛选、导出        特点：单条查看、轻量编辑           特点：多组件、多分区
```

### 18.2 空状态处理

| 场景 | 处理方式 |
|------|----------|
| 列表无数据 | 表格内居中展示空状态（`.empty-state`）：padding 60px 20px，灰色文字 |
| 字段无值 | 统一显示 `--`，不留空白 |
| 搜索无结果 | 提示「未找到相关数据，请调整筛选条件」 |
| 配置未设置 | 显示 placeholder 级别的灰色提示文字 |

### 18.3 加载与反馈

| 场景 | 规范 |
|------|------|
| 列表加载 | 骨架屏或全表格 loading 覆盖 |
| 按钮点击 | 立即禁用并显示 loading 状态，防止重复提交 |
| 保存成功 | 顶部 Toast 提示（详见 §24） |
| 删除 / 危险操作 | 必须弹 Confirm 二次确认后再执行 |
| 表单校验 | 提交时统一校验，错误项红色边框 + 行内错误提示（详见 §27） |
| 接口异常 | Toast 提示错误信息，不阻断用户继续操作 |

### 18.4 数据安全

| 规则 | 说明 |
|------|------|
| 身份证号 | 详情展示脱敏（前1 + **** + 末1） |
| 手机号 | 列表展示脱敏（前3 + **** + 末4） |
| 机构地址 | 详情页完整展示，列表页适当省略 |
| IP / 接口地址 | 详情弹窗展示，列表页不展示 |

### 18.5 窗口层级（z-index 体系）

| 层级 | z-index | 组件 | 说明 |
|------|---------|------|------|
| 内容层 | `auto` / `1` | 页面内容、表格、表单 | 默认文档流 |
| 悬浮层 | `100` | 下拉菜单（Dropdown）、Tooltip、日期选择面板、Select 下拉列表 | Portal 渲染 |
| 固定层 | `500` | 固定表头（sticky）、固定列、Affix | 跟随滚动 |
| 系统层 | `var(--z-overlay)` / `1000` | 顶部导航栏、**底部系统状态栏（§29）** | 全局固定，横跨全屏 |
| 遮罩层 | `var(--z-modal)` / `1100` | 弹窗遮罩（Modal Mask）、抽屉遮罩 | 阻断交互 |
| 模态层 | `var(--z-modal)` / `1100` | 弹窗（Dialog/Modal）、抽屉（Drawer） | 高于遮罩 |
| 通知层 | `var(--z-toast)` / `3000` | Toast 消息提示 | 最高常规层级 |
| 全局层 | `var(--z-global)` / `5000` | 机构选择器、模板编辑器（全屏覆盖） | 遮罩所有内容 |

> **规则**：
> - 弹窗 z-index ≥ 抽屉 z-index
> - 同时只能有 1 个弹窗或抽屉打开
> - 打开抽屉时不阻断列表滚动，打开弹窗时阻断
> - 标签页不嵌套弹窗中再次打开弹窗（避免遮罩叠遮罩）
> - 模板编辑器为全屏覆盖层（z-index: 5000），打开时遮蔽所有内容

### 18.6 键盘可访问性（v1.4 新增）

#### 焦点可见性

所有可交互元素必须具有清晰的 `:focus-visible` 样式：

| 组件 | focus-visible 样式 |
|------|---------------------|
| 按钮、链接 | `outline: 2px solid #2B7FFF; outline-offset: 2px` |
| 输入框、下拉框 | `border-color: #2B7FFF; box-shadow: 0 0 0 2px rgba(43,127,255,0.2)` |
| 菜单项、表格行 | `outline: 2px solid #2B7FFF; outline-offset: -2px`（内侧描边） |
| 开关 Toggle | `box-shadow: 0 0 0 2px rgba(43,127,255,0.3)` |
| 标签页 | `outline: 2px solid #2B7FFF; outline-offset: 2px` |

#### Tab 键导航顺序

1. 跳过导航（Skip Link）→ 顶部导航 → 左侧菜单 → 主内容区
2. 弹窗打开时，焦点自动移至弹窗内第一个可聚焦元素
3. 弹窗关闭时，焦点回退到触发弹窗的元素
4. `Tab` 前进 / `Shift+Tab` 后退 / `Escape` 关闭弹窗/下拉

#### 动效偏好

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 24. 消息反馈（Feedback）

系统通过四种反馈组件覆盖全部消息场景：Notification（全局 Toast）、Alert（页面内横幅）、Progress（进度条）、Result（结果页）。

### 24.1 Notification 通知提醒（Toast）

从屏幕顶部弹出的全局通知，自动消失（2-3s），适合操作结果反馈。

#### 基础规格

| 属性 | 值 |
|------|------|
| 定位 | `position: fixed`，top: 60px，水平居中，z-index: 3000 |
| 样式 | 语义背景色 + 1px 边框（非左边框） |
| 内边距 | `10px 18px` |
| 字号 | 13px |
| 圆角 | 4px |
| 投影 | `0 6px 16px rgba(0,0,0,0.06)` |
| 动画 | fadeIn 0.3s ease（从上往下滑入） |

#### 类型变体

| 类型 | 背景色 | 边框色 | 图标 | 自动消失 |
|------|--------|--------|------|----------|
| 信息 Info | `#F0F5FF` | `#E6F1FB` | ⓘ 蓝色 | 2 秒 |
| 成功 Success | `#E6F9E6` | `#52C41A` | ✓ 绿色 | 2 秒 |
| 警告 Warning | `#FFF7E6` | `#FA8C16` | ⚠ 橙色 | 3 秒 |
| 错误 Error | `#FFF2F0` | `#FFCCC7` | ✕ 红色 | 3 秒 |

#### 交互规则

| 规则 | 说明 |
|------|------|
| 自动消失 | 显示后按时长自动隐藏 |
| 不阻断操作 | Toast 不阻挡用户继续操作 |
| 可手动关闭 | 鼠标悬浮出现 `×` 关闭按钮，阻止自动消失计时 |
| 堆叠上限 | 同一位置最多堆叠 5 条 |

### 24.2 Alert 警告提示

页面内的横幅提示，常置于模块/页面顶部。与 Toast 的区别：Alert 不自动消失，需用户手动关闭。

| 属性 | 值 |
|------|------|
| 样式 | 语义背景色 + 1px 边框 + 圆角 4px |
| 内边距 | `10px 16px` |
| 结构 | 图标 + 标题（font-weight 500）+ 描述文字（12px）+ `×` 关闭 |
| 类型 | Info / Success / Warning / Error 四种语义 |
| 可选附件 | 内嵌操作链接（如"查看详情 →"） |

### 24.3 Progress 进度条

两种形态：线型进度条和圆形进度环，各支持标准/小尺寸。

| 属性 | 线型标准 | 线型小号 | 圆形标准 | 圆形小号 |
|------|----------|----------|----------|----------|
| 尺寸 | 高 8px | 高 4px | 64×64px | 40×40px |
| 背景 | `#E8E8E8` | `#E8E8E8` | border 5px | border 3px |
| 填充色 | `#2B7FFF` | `#2B7FFF` | `border-top-color` | `border-top-color` |

三种状态：Active（蓝色，百分比文字）、Success（绿色，100%或✓）、Error（红色）。

### 24.4 Result 结果页

重要操作完成后的整页反馈，含图标（56×56px 圆形）、标题（16px/600）、描述文字（13px）、操作按钮。

| 类型 | 图标背景色 | 图标色 | 典型场景 |
|------|-----------|--------|----------|
| 成功 | `#E6F9E6` | `#52C41A` ✓ | 提交成功、操作完成 |
| 失败 | `#FFF2F0` | `#FF4D4F` ✕ | 提交失败、异常中断 |
| 警告 | `#FFF7E6` | `#FA8C16` ⚠ | 部分成功、需人工介入 |
| 信息 | `#F0F5FF` | `#2B7FFF` ⓘ | 状态说明、等待审核 |

多步表单（如患者注册流程）、审核流程、向导式操作。支持小型变体（仅标题，无描述文字）。
