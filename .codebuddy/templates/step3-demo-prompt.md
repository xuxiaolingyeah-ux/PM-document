# Step 3 Demo 生成 Prompt 模板

## 输入

- 需求概要（来自 Step 1）
- 方案对比表 + MVP 范围（来自 Step 2）
- 业务流程 + 功能清单 + 状态机（来自 Step 2.5）
- 页面规划与交互骨架（来自 Step 2.6，含页面清单 / 信息架构 / 低精度线框）
- 设计系统：{Ant Design / shadcn / Tailwind CSS / 自定义}

---

## Prompt 结构

```
你是一个前端开发专家。请基于以下需求，生成一个可交互的 Demo 页面。

## 技术栈
- 框架：{React / Vue / HTML}
- UI 库：{Ant Design 5.x / shadcn / Tailwind CSS}
- 运行方式：单个 HTML 文件，内联 CSS 和 JS，可直接在浏览器打开

## 需求描述
{粘贴需求概要 + 方案中的核心功能描述}

## 页面清单（来自 Step 2.6，已与 PM 对齐）
{列出所有页面}

## 关键状态
每个页面必须覆盖以下状态：
- 正常态：数据正常展示
- 空态：无数据时的展示
- 加载态：数据加载中的展示
- 错误态：请求失败时的展示和重试机制
- 边界情况：极限数据（超长文本、大量数据等）

## 核心交互
{列出核心用户操作流程，用序号标注步骤}

## 设计约束
- 主色：{品牌色}
- 字体层级：标题 / 正文 / 辅助文字
- 间距规范：{8px 倍数或其他}
- 圆角：{数值}

## 输出要求
1. 生成单个完整 HTML 文件
2. 包含所有页面的切换逻辑
3. 使用模拟数据，可点击交互
```
