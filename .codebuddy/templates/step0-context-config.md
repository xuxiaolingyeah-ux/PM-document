# Step 0 上下文配置卡

> 注：技术栈、组件库属研发决策，不在本步由 PM 填写；迭代项目在 Step 3 由研发提供，或 AI 直接读取现有代码库/设计令牌。

## 0→1 新项目

| 必填项 | 说明 | 示例 |
|--------|------|------|
| 目标用户 | 谁会使用这个产品？ | "独立开发者，月收入 $500-$5000" |
| 行业/赛道 | 产品属于哪个领域？ | "SaaS 订阅管理 / 开发者工具" |
| 核心场景 | 用户什么时候会用到？ | "每月收到多笔 SaaS 扣款时，想统一查看和管理" |
| 核心痛点 | 现在怎么解决的？为什么不够好？ | "用 Excel 手动记录，经常漏掉取消订阅" |
| 参考产品 | 竞品或参考对象有哪些？ | "Truebill / Rocket Money" |

| 可选项 | 说明 |
|--------|------|
| 设计风格参考 | 喜欢的同类产品风格 |
